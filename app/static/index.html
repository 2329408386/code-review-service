代码仓管理

隐藏的代码仓不再纳入数据统计，也不在检视记录中显示，但新的 MR 仍会照常检视与回写。代码仓可归入自定义分组，数据统计可按分组查看。

仅管理员可修改配置，请先登录。

模型路由

每条路由独立配置 Base URL、API Key、思考强度和并发；代码仓绑定到路由，未绑定的仓库使用“兜底”路由。Base URL 留空时使用服务端 .env 中的默认网关。API Key 只保存在服务端，不会回显。

仅管理员可修改配置，请先登录。

检视范围

为代码仓配置允许的目标分支后，只有合入这些分支的 MR 会被检视，其余记为“已忽略”；未配置的代码仓不受影响。分支名精确匹配、区分大小写。

仅管理员可修改配置，请先登录。
